# 6-Month Plan

## Success Criteria

By the end of six months, this repository should contain:

- Five polished portfolio projects.
- At least twenty paper or technical reading notes.
- A complete ML/DL/LLM foundations map.
- Evidence of Python, NumPy, scikit-learn, PyTorch, and LLM system work.
- Interview preparation notes for coding, ML, math, and research discussions.

## Month 1: Python, Math, and Classical ML

Goals:

- Become faster with Python, NumPy, pandas, plotting, and clean notebooks.
- Review linear algebra, probability, gradients, and optimization.
- Implement and explain classical ML baselines.

Deliverables:

- NumPy vectorization notes.
- Linear regression and logistic regression notes.
- First baseline experiment in `06-projects/project-01-ml-baseline/`.
- Weekly log entries for each week.

## Month 2: Evaluation and Applied ML

Goals:

- Build practical modeling habits.
- Understand metrics, leakage, validation, calibration, and error analysis.
- Practice coding interviews in Python.

Deliverables:

- Model evaluation checklist.
- scikit-learn pipeline experiment.
- Error analysis report.
- First set of ML interview questions answered.

## Month 3: Deep Learning and PyTorch

Goals:

- Build reliable PyTorch training loops.
- Understand backpropagation, initialization, regularization, optimizers, and debugging.
- Train at least one neural network end to end.

Deliverables:

- PyTorch training loop template.
- Learning curve and failure analysis notes.
- Project 02 write-up in `06-projects/project-02-pytorch-model/`.
- Paper review on a deep learning architecture.

## Month 4: Transformers and LLM Systems

Goals:

- Understand attention, tokenization, transformer blocks, and decoder-only language models.
- Study LLM evaluation, RAG, fine-tuning, and serving constraints.
- Build a small transformer or RAG prototype.

Deliverables:

- Transformer architecture notes.
- RAG design document.
- Project 03 or Project 04 first version.
- LLM evaluation checklist.

## Month 5: Paper-to-Code and Research Practice

Goals:

- Read papers more like a researcher.
- Convert one paper into an implementation plan.
- Run controlled experiments and ablations.

Deliverables:

- Five paper reviews.
- One reproduction report.
- Experiment design document.
- Project 05 first version.

## Month 6: Portfolio Polish and Interview Readiness

Goals:

- Make projects easy to inspect.
- Practice explaining technical choices.
- Prepare for coding, ML, math, and research interviews.

Deliverables:

- Polished README and project pages.
- Research talk notes.
- Mock interview question bank.
- Final skill matrix update.
