# Google AI Intern Prep

Preparation repository for becoming a strong AI research internship candidate. The repository combines Python coding, ML foundations, deep learning, LLM systems, research practice, portfolio projects, and interview preparation.

## Objective

Build visible evidence of research readiness:

- Strong Python and numerical computing habits.
- Solid mathematical and machine learning foundations.
- Practical PyTorch and deep learning implementation skills.
- Understanding of transformers, LLM evaluation, RAG, and serving tradeoffs.
- Ability to read papers, design experiments, reproduce ideas, and communicate results clearly.

## Current Focus

| Track | Output |
| --- | --- |
| Python coding | Clean implementations, algorithm notes, NumPy vectorization drills |
| ML foundations | Model notes, evaluation reports, baseline experiments |
| Deep learning | PyTorch training loops, diagnostics, model write-ups |
| LLM systems | Transformer notes, RAG prototype, evaluation checklists |
| Research | Paper reviews, experiment plans, reproduction reports |
| Interview prep | Coding practice, ML questions, research discussion notes |

## Structure

- `00-roadmap/`: Planning, weekly logs, and skill tracking.
- `01-python-coding/`: Python, algorithms, NumPy, and clean code.
- `02-ml-foundations/`: Classical ML and math.
- `03-deep-learning/`: PyTorch, neural networks, CNNs, transformers.
- `04-llm-systems/`: LLM architecture, RAG, evaluation, and serving.
- `05-research/`: Paper reviews and open research questions.
- `06-projects/`: Portfolio projects.
- `07-interview-prep/`: Coding, ML, math, and research interview notes.

## Weekly Operating System

Each week should produce at least:

- One technical note.
- One coding artifact or experiment.
- One paper summary or research discussion note.
- One short reflection in `00-roadmap/weekly-log.md`.

## Portfolio Projects

1. Classical ML baseline with rigorous evaluation.
2. PyTorch model with reproducible training.
3. Small transformer implementation.
4. Retrieval-augmented generation system.
5. Research reproduction from a selected paper.

## Quality Bar

Every serious project should include the problem, data, baseline, method, metrics, results, limitations, and next steps.
