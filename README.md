# Google AI Intern Prep

Preparation repository for becoming a strong AI research internship candidate. It combines Python coding, ML foundations, deep learning, LLM systems, research practice, projects, and interview preparation.

## Core Signal

This repository is designed to show learning velocity, technical clarity, reproducible experiments, and the ability to connect research ideas to working code.

## Structure

- `00-roadmap/`: Planning, weekly logs, and skill tracking.
- `01-python-coding/`: Python, algorithms, NumPy, and clean code.
- `02-ml-foundations/`: Classical ML and math.
- `03-deep-learning/`: PyTorch, neural networks, CNNs, transformers.
- `04-llm-systems/`: LLM architecture, RAG, evaluation, and serving.
- `05-research/`: Paper reviews and open research questions.
- `06-projects/`: Portfolio projects.
- `07-interview-prep/`: Coding, ML, math, and research interview notes.
